Micro Core communication
#######################

The experimental Micro Core subsystem provides a bounded, transport-neutral
reliable byte link and an ID-based message layer for application-supplied
transports.

This port is based on the contributor-owned Micro Core ``dev`` branch at
commit ``818e9e7``. It is an experimental Zephyr implementation and is not a
safety certification or a compatibility guarantee for the standalone API.
